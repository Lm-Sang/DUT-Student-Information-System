## Cập nhật surface xanh

Đợt cập nhật theo UI_sample3 (V1) và UI_sample + UI_sample2 (V2) giữ nguyên 66 frame ID, tái sử dụng đủ 122 main component ID. Token `editions` được scope tại `.portal-v1`/`.portal-v2`; Figma dùng hai collection hiện hữu. [Palette specimen](https://www.figma.com/design/hq4ifJ2w6AjspNHzSafral/DUT-Student-Portal?node-id=349-2229). Báo cáo hiện hành: [V1](v1-redesign-report.md), [V2](v2-redesign-report.md).

## Color system 1.3 — neutral-first

Đã đồng bộ màu tại chỗ cho 66 screen và 122 component trong `figma-redesign-map.json`, giữ frame/component IDs. Palette `349:2229`, Button set `247:2129` (24 states) được cập nhật, không tạo frame mới. Các biến và effect style giữ cấu trúc hiện có; thêm semantic roles còn thiếu. Quy tắc và kiểm chứng thuộc [Brand Color System](brand-color-system.md).
