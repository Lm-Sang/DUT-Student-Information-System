# UI_ANTI_PATTERNS.md — Avoid Generic / AI-Looking UI

Defaults to avoid, not absolute bans.

## Visual
Avoid by default:
- generic purple/blue gradients;
- glassmorphism without a reason;
- decorative glow;
- giant rounded page wrappers;
- cards nested inside cards;
- excessive shadows;
- every control as a pill;
- random abstract blobs;
- arbitrary heading gradients;
- oversized marketing typography in dense app screens;
- meaningless decorative badges.

## Layout
Avoid:
- generic three-equal-card sections when content is not three peers;
- fake KPI cards;
- excessive centered layouts for data-heavy screens;
- huge empty hero areas above routine workflows;
- wrappers that weaken hierarchy;
- hover-only essential actions.

## Content
Avoid fake metrics, fake testimonials, invented capabilities, buzzword-heavy operational copy, and whimsical empty states that conflict with tone.

## Interaction
Avoid custom controls duplicating native semantics, motion on every hover, scroll-jacking, surprise horizontal scrolling, unlabeled icon buttons, disabled browser zoom, or placeholder-only field labels.

## Agent behavior
Do not redesign unrelated areas, replace an existing design system during a local task, invent one-off visual values, clone another brand, or add decoration merely to demonstrate creativity.
